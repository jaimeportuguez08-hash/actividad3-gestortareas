# Actividad 3 - Aplicación interactiva con JavaScript moderno

Aplicación web sencilla para administrar tareas escolares, laborales y personales.

## Cómo abrir

1. Abre esta carpeta en Visual Studio Code.
2. Se recomienda abrir `index.html` con Live Server.
3. Agrega una tarea y utiliza los filtros para probar la aplicación.

## Requisitos incluidos

- Alta, visualización, edición y eliminación de registros.
- Datos modelados como objetos y almacenados en un arreglo.
- Manipulación del DOM para actualizar la lista y los contadores.
- Eventos de formulario, botones, búsqueda y filtros.
- Sintaxis moderna de JavaScript (`const`, `let`, funciones flecha, template literals, `Array.filter`, `Array.sort`, `find`, `findIndex` y `localStorage`).
- Validación de datos y mensajes para el usuario.
- Persistencia y recuperación de tareas mediante `localStorage`.
- Funciones adicionales: búsqueda, filtros, ordenamiento, prioridades, categorías y contadores.
- Diseño adaptable a móvil, tableta y escritorio.

## Cómo funciona el guardado

La información se guarda automáticamente en el almacenamiento local del navegador. Los datos permanecen en el navegador y dispositivo donde se utiliza la aplicación; no se envían a un servidor.

## Demostración sugerida de 3 minutos

1. Crear una tarea con categoría, prioridad y fecha.
2. Buscarla y filtrar por categoría.
3. Editar su título o fecha.
4. Marcarla como completada y mostrar el cambio en los contadores.
5. Recargar la página para mostrar que la tarea sigue guardada.
